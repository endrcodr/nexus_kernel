# Nexus: the OS kernel built around modularity
Nexus is a stripped-down kernel that can schedule events, manage memory, and manage and execute modules built on top. It is designed so that any and all features, including a filesystem, drivers, controllers, peripheral access, and graphical output are all added in as needed. You put a package with the kernel, build the kernel, and now it detects and executes the package.
In other words, it only has what you need. It is equally capable of a desktop environment as it is a handheld gaming console.

# Usage
Usage of the Nexus kernel is only as limited as your creativity is. As an endgame, we hope that rebuilding the kernel with a new package and updating the kernel live will be achievable without any form of restart and yet still be safe.

# Functionality
The Nexus kernel uses a binary file system for its core systems, and an external file system package is required for compatibility with any form of standard file system.
